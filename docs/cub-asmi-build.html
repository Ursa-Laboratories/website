Build process · Cub + ASMI

Build a Cub with the ASMI indenter

Turn a Genmitsu 3018-PROVer V2 into an automated indentation tester that measures the mechanical properties of samples in a 96-well plate. Work through the six parts in order; each ends with a short check so you know it worked before moving on.

The six parts

  1. AAssemble the gantry2 hoursBuild the Genmitsu 3018-PROVer V2 kit exactly as Genmitsu describes, except for the spindle, acrylic baffle and cable ties noted below.
  2. BMount the ASMI force sensor45 minutesClamp the Vernier force sensor in its printed mount and fit it to the gantry's Z axis. This is the ASMI's indenting head.
  3. CBring up the gantry30 minutesSet the controller's firmware so the machine homes to the back-right-top corner and every axis moves the right way. CubOS relies on this and never flips axes in software.
  4. DInstall CubOS15 minutesInstall CubOS, the software that runs the gantry and the force sensor, and open its Operator window.
  5. ECalibrate the gantry15 minutesTeach CubOS where the deck is and how far each axis can travel, using a printed calibration block and the indenter tip.
  6. FCalibrate labware5 minutes per plateRecord exactly where your 96-well plate sits so the indenter lands in the centre of every well.

What else you need

Tools

  • A Mac or Windows computer
  • The Allen wrenches and Phillips wrench included with the Genmitsu kit
  • Calipers
  • A 3D printer, if you're printing the mounts yourself

Software

  • Universal Gcode Sender (part C only)
  • CubOS (part D)
Caution

Never leave the gantry running unattended during bring-up or calibration, and keep the E-stop within reach whenever it's powered.
