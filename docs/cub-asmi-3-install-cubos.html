Install CubOS

Install CubOS, the software that runs the gantry and the force sensor, and open its Operator window.

What you need

  • A Mac or a Windows PC with the gantry's USB cable plugged in
  • Mac only: an internet connection and about 1 GB of disk space

Choose the path for your computer. Both end with the CubOS Operator open, showing the Workflow, Visualize, State and Results tabs.

Steps

1Windows: run the installer

  1. Go to the latest CubOS release and download CubOS-Setup-….exe under Assets.
  2. Run it. It doesn't need administrator rights, Python or Git.
  3. Open CubOS from the Start menu or desktop shortcut. The Operator opens in its own window.

Your configuration files live in %LOCALAPPDATA%\UrsaLabs\CubOS\configs.

2Mac: install the tools

If you don't have Homebrew, install it first. Then, in Terminal:

brew install python@3.11 git node

3Mac: download and install CubOS

git clone https://github.com/Ursa-Laboratories/CubOS.git
cd CubOS
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -e "packages/core[dev,asmi-vernier]"
python -m pip install -e services/api

asmi-vernier adds the driver for the Vernier force sensor.

4Mac: build the Operator screen

This only needs doing once (and again after updating CubOS):

cd apps/operator-web && npm ci && npm run build && cd ../..

5Mac: start CubOS

source .venv/bin/activate
python -m cubos_api

Open http://127.0.0.1:8742 in your browser. Leave the Terminal window open while you use CubOS.

Tip

No module named cubos_api means the source .venv/bin/activate line was skipped. A page saying compiled web assets weren't found means the build step above didn't run.

Check your work

  • The CubOS Operator is open with the Workflow, Visualize, State and Results tabs.
  • UGS is closed, so CubOS can use the USB port.
