Calibrate the gantry

Teach CubOS where the deck is and how far each axis can travel, using a printed calibration block and the indenter tip.

What you need

  • Printed calibration block and CubXL calibration base (print and mounting guide)
  • Calipers to measure the block height
  • The CubOS Operator from part D

Calibration sets the deck's zero point, the indenter's height, and the machine's real travel, and saves them to your gantry file. Redo it after a crash or any mechanical change.

Steps

1Place the calibration block

Seat the CubXL calibration base's peg in a hole near a corner of the baseplate, then set the block on the base so its four diamond-shaped feet drop into the matching holes. Measure the block's height with calipers.

Tip

The wizard tells you which corner it expects (front-left on a default setup). Put the block there.

2Load the Cub gantry file and connect

  1. In the Workflow tab, open Gantry and choose cub_xl_asmi.yaml (or the gantry file that shipped with your machine).
  2. Click Connect in the Gantry Control panel. The status dot turns green when the USB link is up. CubOS never moves on its own when it connects.
Caution

If CubOS reports a GRBL settings mismatch, the controller doesn't match what part C set. Go back and check $3, $20, $22 and $23.

3Run the calibration wizard

Click Calibrate. For a single-instrument CubXL the wizard has five steps:

  1. Prepare — optionally enter a new output file name to keep the original file untouched.
  2. Home — click Home gantry.
  3. Reference height — enter the block height you measured.
  4. Set origin — jog the indenter over the block and down until the ball just touches the block's top surface. Switch to 0.1 mm steps for the last few millimetres.
  5. Save — clear the deck. The gantry re-homes, measures its travel and writes the gantry file.
Caution

Jog down slowly near the block. The force sensor is the instrument you're protecting.

4Check the result

Jog a few millimetres in each direction from the Operator. +X should move right, +Y toward the back, +Z up, and the position readout should match what you see.

Check your work

  • The wizard's Save step finished without errors.
  • Jogging from the Operator moves the right way on every axis.
