CubXL Gantry

Assemble the CubXL from the Genmitsu PROVerXL 4030 V2 CNC Router Kit. Some work is completed before shipping; use this guide as the assembly source of truth and consult the Genmitsu manual only at the referenced steps.

Source: CubXL - Gantry User Manual, Rev. 2.

Assembly steps

  1. Confirm Y-axis roller module position. Refer to Step 1. The modules should already be behind the green tape and butted against the mechanical stop, as close to the Y-axis motors as possible.
  2. Install the X-axis module. Refer to Step 2, then remove the green tape.
  3. Skip installing the XZ-axis module. It is already installed. It does not include the spindle; ignore spindle references in the Genmitsu manual.
  4. Install the lead-screw coupler and X-axis motor. Refer to Step 4. The coupler is already installed on the motor; install the motor in the proper orientation.
  5. Install the Y-axis drag-chain brackets. Refer to Step 5.
  6. Install the Y-axis drag chain. Refer to Step 6. The X/Y drag chain and wiring arrive assembled. Install the end with the twelve screw-lock cables on bracket A, observing the source figures for orientation.
  7. Skip installing the X-axis drag-chain bracket. Brackets A/B are already installed on the X-axis module.
  8. Install the X-axis drag-chain cable. Refer to Step 8 and install the free end of the X/Y drag chain on X-axis drag-chain bracket B.
  9. Finish wiring. Follow the Genmitsu wiring diagrams and disregard spindle motor wiring.
  10. Connect the Raspberry Pi. Use the source wiring figure as the reference for the Vernier sensor cable, USB A-to-B cable, and Raspberry Pi power adapter.

Mounts

Vernier Go Direct mount

  1. Gather the Vernier mount, sensor, six M4 x 16 mm socket head screws, two M5 x 15 mm button head screws, two M5 hex nuts, and the 3 mm Allen wrench.
  2. Place the Vernier sensor in the rectangular opening in the back half of the mount, following the source orientation.
  3. Place the cover over the assembled sensor and mount.
  4. Install the six M4 screws above the sensor. Install the two M5 screws below it and the two M5 nuts in the rear hex cavities; tighten until snug and clamping the sensor.
  5. Screw either a 5 mm or 3 mm ball indenter into the sensor, depending on testing needs.
  6. Align the six screws with the six holes on the X-axis module and tighten snugly. Plug the sensor cable into the side of the sensor.

Adding mounts to the baseplate

The source says this method applies to the CUBXL ASMI wellplate mount and heater plate holder; the following example uses four screws and four nuts for the ASMI mount. The Hamilton holder uses two screws and two nuts.

  1. Align the mount’s four holes with holes in the gantry baseplate.
  2. Place four M5 x 15 mm button head screws through the aligned holes.
  3. From underneath the baseplate, fasten four M5 hex nuts and tighten until the mount does not move.

CubOS software setup

These steps describe the prepared Raspberry Pi supplied with the source kit. Use your machine’s setup network and hostname; the source’s network name is an example.

  1. What you need: the assembled machine with Raspberry Pi and power supply, a phone or laptop, and optionally an Ethernet cable.
  2. Power on: connect power and allow about one minute for the Pi and CubOS operator to boot.
  3. Connect to the network: for this source example, use the Wi-Fi setup network CubOS-FEF7 with password cubsetup, or connect the Pi to a router by Ethernet. For Wi-Fi, browse to 192.168.42.1 if the setup page does not open automatically; choose your network and connect. Enterprise networks requiring a username are not supported, and client-isolated guest networks may block access.
  4. Open the operator: on the same network, open http://cub.local:8742, or use the machine IP address.
  5. Connect the hardware: in Workflow, choose the gantry configuration, such as cub_xl_asmi.yaml, and press Connect. The status dot turns green when the serial link is up.
  6. Continue: proceed with homing, calibration, deck setup, and protocols in the CubOS documentation.
